Klarwert

Local-first portfolio analyzer for Trade Republic

Drop in your Trade Republic CSV export and get an audit trail, a per-year tax report, performance metrics, unrealized P&L, income and spending analytics, and position concentration — all on your own machine.

View on GitHub

All computation happens on your machine. Your data never leaves it.

What it does

Reconciliation

Sources vs. uses of cash, including trade fees and taxes.

Monthly Realized P&L

Realized profit and loss per month, charted.

FIFO Audit Trail

Per-lot sale matches: buy date, cost basis, proceeds, P&L.

Tax Report

Per-fiscal-year disposals with CSV export.

Dividends & Income

Gross/WHT/net dividends, yield on cost, stacked income charts.

Cash Flow & Spending

Deposits, withdrawals, balances and card spending by MCC category.

Derivative Executions

Warrant and knock-out exercises, including knocked-down lots.

Product Charts

Allocation by product and dividend history.

Quick start

  1. git clone git@github.com:d0k3n/klarwert.git
  2. cd klarwert && python -m venv venv
  3. source venv/bin/activate && pip install -r requirements.txt
  4. python app.py — then open http://127.0.0.1:5000
